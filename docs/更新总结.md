**新增文件**：

**核心功能**：
- `DataAuditor` 类 - 数据审计器
  - `audit_trading_calendar()` - 审计交易日历完整性
  - `audit_stock_universe()` - 审计股票池覆盖度
  - `audit_market_data_availability()` - 审计市场数据可用性（抽样）
  - `run_full_audit()` - 运行完整审计流程
  - `get_audit_report()` - 获取审计历史报告

**检查标准**：
- 交易日数 ≥ 200天
- 股票数量 ≥ 1000只
- 数据成功率 ≥ 70%

**API 端点**：
- `GET /api/audit?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD` - 运行数据审计

### 3. 实现区间管理功能（锁定历史回测区间）

**新增文件**：
- `backend/period_manager.py` - 区间管理模块（327行）

**核心功能**：
- `PeriodManager` 类 - 区间管理器
  - `define_period()` - 定义新区间
  - `lock_period()` - 锁定区间（防止误用封存数据）
  - `unlock_period()` - 解锁区间（需强制确认）
  - `list_periods()` - 列出所有区间
  - `validate_backtest_request()` - 验证回测请求是否在允许的区间内
  - `print_summary()` - 打印区间配置摘要

**区间类型**：
- `research` - 研究区间（用于策略开发和调参）
- `validation` - 验证区间（独立验证策略效果）
- `reserved` - 封存区间（样本外测试，慎用）

**默认配置**：
- research_2020_2022: 2020-01-01 至 2022-12-31
- validation_2023: 2023-01-01 至 2023-12-31
- reserved_2024: 2024-01-01 至 2024-12-31

**API 端点**：
- `GET /api/periods` - 查看所有区间
- `POST /api/periods/lock?period_name=xxx` - 锁定指定区间

**配置文件**：
- `data/periods.json` - 区间配置持久化

```bash
curl "http://127.0.0.1:8001/api/audit?start_date=2023-01-01&end_date=2023-12-31"
```

### 2. 查看区间配置

```bash
curl http://127.0.0.1:8001/api/periods
```

### 3. 锁定研究区间

```bash
curl -X POST "http://127.0.0.1:8001/api/periods/lock?period_name=research_2020_2022"
```

### 4. 运行完整版回测

```bash
# 主板回测（推荐）

    "start_date": "2023-01-01",
    "end_date": "2023-12-31",
    "stock_filter": "mainboard",
    "max_symbols": null
  }'

  -H "Content-Type: application/json" \
  -d '{
```
