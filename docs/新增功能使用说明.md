# 新增功能使用说明

## 概述

本次更新实现了**完整版回测系统**，去掉了简化版限制，并新增了两个关键功能模块：

1. **数据审计功能** - 验证历史数据的完整性和可靠性
2. **区间管理功能** - 管理和锁定历史回测区间，避免过拟合

---

## 1. 数据审计功能

### 功能说明

数据审计用于验证回测所需数据的质量，包括：
- **交易日历完整性** - 检查指定区间的交易日数量
- **股票池覆盖度** - 验证能获取到足够数量的股票
- **市场数据可用性** - 抽样检查行情数据的获取成功率

只有数据审计通过后，才能确保回测结果可信。

### API 使用

#### 运行完整审计

```bash
curl "http://127.0.0.1:8001/api/audit?start_date=2023-01-01&end_date=2023-12-31"
```

**响应示例**：

    "stock_universe": {

### Python 代码使用

```python
from backend.data_audit import DataAuditor

auditor = DataAuditor()

# 运行完整审计
report = auditor.run_full_audit(
    start_date="2023-01-01",
    end_date="2023-12-31",
    min_trading_days=200,
    min_symbols=1000
)

if report['passed']:
    print("✓ 数据审计通过，可以进行回测")
else:
    print("✗ 数据审计未通过，请检查数据质量")
```

### 审计标准

| 检查项 | 默认标准 | 说明 |
|--------|---------|------|
| 交易日数 | ≥200天 | 确保有足够的历史数据 |
| 股票数量 | ≥1000只 | 覆盖主要市场股票 |
| 数据成功率 | ≥70% | 抽样20只股票，至少14只能获取数据 |

## 2. 区间管理功能

### 功能说明

区间管理用于定义和锁定历史回测区间，遵循**研究/验证/封存**原则：

- **研究区间（research）** - 用于策略开发和参数调优
- **验证区间（validation）** - 独立验证策略效果
- **封存区间（reserved）** - 保留作为真正的样本外测试

锁定后的区间可以防止意外使用封存数据，保证样本外验证的有效性。

### API 使用

#### 查看所有区间

```bash
curl http://127.0.0.1:8001/api/periods
```

**响应示例**：
```json
{
  "total_periods": 3,
  "by_purpose": {
    "research": 1,
    "validation": 1,
    "reserved": 1
  },
  "locked_periods": ["research_2020_2022"],
  "periods": [
    {
      "name": "research_2020_2022",
      "start_date": "2020-01-01",
      "end_date": "2022-12-31",
      "purpose": "research",
      "locked": true,
      "description": "研究区间：用于策略开发和参数调优"
    },
    {
      "name": "validation_2023",
      "start_date": "2023-01-01",
      "end_date": "2023-12-31",
      "purpose": "validation",
      "locked": false,
      "description": "验证区间：独立验证策略效果"
    }
  ]
}
```

#### 锁定区间

```bash
curl -X POST "http://127.0.0.1:8001/api/periods/lock?period_name=research_2020_2022"
```

**响应示例**：
```json
{
  "success": true,
  "message": "区间 'research_2020_2022' 已锁定",
  "period": {
    "name": "research_2020_2022",
    "locked": true
  }
}
```

### Python 代码使用

```python
from backend.period_manager import PeriodManager

manager = PeriodManager()

# 查看当前配置
manager.print_summary()

# 定义新区间
manager.define_period(
    name="research_2025",
    start_date="2025-01-01",
    end_date="2025-12-31",
    purpose="research",
    description="2025年研究区间"
)

# 锁定区间
manager.lock_period("research_2020_2022")

# 验证回测请求
validation = manager.validate_backtest_request(
    start_date="2020-01-01",
    end_date="2022-12-31",
    allowed_purposes=["research"]
)

if validation['valid']:
    print("✓ 回测请求有效")
    for warning in validation.get('warnings', []):
        print(f"⚠️ {warning}")
```

### 默认区间配置

系统初始化时会创建三个默认区间：

| 区间名称 | 时间范围 | 用途 | 说明 |
|---------|---------|------|------|
| research_2020_2022 | 2020-2022 | 研究 | 用于策略开发和调参 |
| validation_2023 | 2023 | 验证 | 独立验证策略效果 |
| reserved_2024 | 2024 | 封存 | 样本外测试（慎用）|

**配置文件位置**：`data/periods.json`

## 3. 完整版回测

### 功能说明

完整版回测去掉了股票数量限制，支持：
- **全市场回测** - 加载所有沪深A股
- **主板回测** - 仅主板股票（推荐）
- **样本测试** - 20只股票快速测试

### API 使用

```bash
curl -X POST http://127.0.0.1:8001/api/backtest \
  -H "Content-Type: application/json" \
  -d '{
    "start_date": "2023-01-01",
    "end_date": "2023-12-31",
    "initial_cash": 1000000,
    "target_stocks": 30,
    "target_budget": 0.9,
    "min_adv20": 20000000,
    "slippage_bps": 5.0,
    "commission_rate": 0.0003,
    "stock_filter": "mainboard",
    "max_symbols": null
  }'
```

### 新增参数

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| `stock_filter` | string | "mainboard" | 股票过滤方式：<br>- "all": 全市场<br>- "mainboard": 仅主板<br>- "sample": 样本测试 |
| `max_symbols` | int/null | null | 最大股票数限制，null表示不限制 |

### 示例：全市场回测

```bash
curl -X POST http://127.0.0.1:8001/api/backtest \
  -H "Content-Type: application/json" \
  -d '{
    "start_date": "2023-01-01",
    "end_date": "2023-12-31",
    "stock_filter": "all",
    "max_symbols": null
  }'
```

### 示例：限制最多1000只股票

```bash
curl -X POST http://127.0.0.1:8001/api/backtest \
  -H "Content-Type: application/json" \
  -d '{
    "start_date": "2023-01-01",
    "end_date": "2023-12-31",
    "stock_filter": "mainboard",
    "max_symbols": 1000
  }'
```

## 4. 使用建议

### 推荐工作流程

1. **运行数据审计**
   ```bash
   curl "http://127.0.0.1:8001/api/audit?start_date=2023-01-01&end_date=2023-12-31"
   ```

2. **查看区间配置**
   ```bash
   curl http://127.0.0.1:8001/api/periods
   ```

3. **锁定研究区间**
   ```bash
   curl -X POST "http://127.0.0.1:8001/api/periods/lock?period_name=research_2020_2022"
   ```

4. **运行回测**（在已锁定的研究区间内）
   ```bash
   curl -X POST http://127.0.0.1:8001/api/backtest \
     -H "Content-Type: application/json" \
     -d '{"start_date": "2020-01-01", "end_date": "2022-12-31", ...}'
   ```

### 注意事项

1. **数据审计**
   - 首次使用时建议先运行审计，确保数据质量
   - 审计会抽样检查，不会下载所有数据
   - 审计失败时检查网络和 akshare 是否正常

2. **区间管理**
   - 锁定区间前确认不再需要调整
   - 封存区间一旦使用就不再是"样本外"
   - 可以通过修改 `data/periods.json` 自定义区间

3. **完整版回测**
   - 首次运行会下载数据，可能需要较长时间
   - 使用缓存后速度会明显提升
   - 建议先用 `stock_filter="sample"` 测试流程

## 5. 常见问题

### Q1: 数据审计失败怎么办？

**A**: 检查以下几点：
- 确保安装了 `akshare`：`uv pip install akshare`
- 检查网络连接
- 尝试缩短日期范围
- 降低审计标准（修改 `min_trading_days` 和 `min_symbols`）

### Q2: 如何解锁已锁定的区间？

**A**: 需要使用 Python 代码：
```python
from backend.period_manager import PeriodManager
manager = PeriodManager()
manager.unlock_period("research_2020_2022", force=True)
```

### Q3: 全市场回测需要多长时间？

**A**: 取决于：
- 日期范围（1年约 4000+ 只股票）
- 网络速度
- 是否使用缓存

首次运行可能需要 1-2 小时，使用缓存后只需几分钟。

### Q4: 如何修改默认区间配置？

**A**: 编辑 `data/periods.json` 或使用代码：
```python
manager = PeriodManager()
manager.define_period(
    name="my_period",
    start_date="2025-01-01",
    end_date="2025-12-31",
    purpose="research",
    description="自定义区间"
)
```
