## 1️⃣ 数据模块 (`backend/data.py`)

**功能**：提供历史数据获取、交易日历、股票池构建等基础数据服务

### 核心函数

#### `fetch_trading_calendar(start, end)`
**功能**：获取交易日历

**输入**：
- `start`: str - 起始日期 "YYYY-MM-DD"
- `end`: str - 结束日期 "YYYY-MM-DD"

**输出**：
- DataFrame，列：`trade_date`

**用途**：识别月末交易日、确定调仓日

---

#### `fetch_stock_list(date=None)`
**功能**：获取沪深A股列表

**输入**：
- `date`: str | None - 指定日期（None表示当前）

**输出**：
- DataFrame，列：`symbol`, `name`, `exchange`, `list_date`

**用途**：构建历史股票池

---

#### `fetch_daily_quotes(symbol, start, end)`
**功能**：获取日线行情（未复权）

**输入**：
- `symbol`: str - 标准格式股票代码（如"SZ.000001"）
- `start`: str - 起始日期
- `end`: str - 结束日期

**输出**：
- DataFrame，列：`date`, `open`, `high`, `low`, `close`, `volume`, `amount`

**用途**：获取收盘价、开盘价、成交额

---

#### `calculate_adv20(quotes, target_date)`
**功能**：计算20日平均成交额（ADV20）

**输入**：
- `quotes`: DataFrame - 日线行情数据
- `target_date`: str - 目标日期

**输出**：
- float - ADV20值（元），数据不足返回0

**用途**：流动性过滤

**算法**：
```python
# 获取目标日期之前的20个交易日
before = quotes[quotes["date"] <= target_date].tail(20)
# 停牌日成交额视为0
adv20 = before["amount"].fillna(0).mean()
```

---

#### `fetch_market_cap(symbol, date)`
**功能**：获取指定日期的总市值

**输入**：
- `symbol`: str - 股票代码
- `date`: str - 日期

**输出**：
- float | None - 总市值（元），失败返回None

**用途**：市值排序

---

#### `UniverseBuilder` 类
**功能**：历史股票池构建器

**方法**：

- `get_month_ends(start, end)` → list[str]
  - 获取区间内的月末交易日列表

- `filter_basic_eligibility(stock_info, date)` → DataFrame
  - 基础资格过滤（当前为框架，待实现ST/退市过滤）

## 5️⃣ 选股模块 (`backend/selection.py`)

**功能**：实现小市值选股逻辑，包括过滤、排序、权重分配

### 核心类

#### `SelectionConfig` (配置类)
**功能**：选股参数配置

**参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `target_stocks` | int | 30 | 目标持股数量 |
| `target_budget` | float | 0.9 | 目标股票预算比例（90%） |
| `min_adv20` | float | 20,000,000 | 最低20日平均成交额（元） |
| `min_percentile` | float | 0.01 | 市值百分位下限（排除最小1%） |
| `max_percentile` | float | 0.20 | 市值百分位上限（前20%） |
| `min_listed_days` | int | 250 | 最低上市交易日数 |

**验证**：
- `target_stocks`: 1-100
- `target_budget`: 0.01-1.0
- `min_percentile < max_percentile`

---

#### `StockCandidate` (数据类)
**功能**：候选股票信息

**字段**：
- `symbol`: str - 股票代码
- `market_cap`: float - 总市值
- `adv20`: float - 20日平均成交额
- `rank`: int - 市值排名（1=最小）
- `percentile`: float - 百分位（0-1）
- `close`: float - 收盘价
- `trading_status`: str - 交易状态（"trading"/"suspended"）
- `risk_status`: str - 风险状态（"normal"/"st"/"delisted"）
- `listed_days`: int - 上市交易日数

---

#### `SmallCapSelector` 类
**功能**：小市值选股器

**方法 1**: `select()`

**功能**：执行完整选股流程

**输入**：
- `universe`: DataFrame - 历史股票池，必须包含`symbol`列
- `market_caps`: dict[str, float] - 总市值字典
- `adv20_values`: dict[str, float] - ADV20字典
- `prices`: dict[str, float] - 收盘价字典
- `trading_status`: dict[str, str] | None - 交易状态（默认全部"trading"）
- `risk_status`: dict[str, str] | None - 风险状态（默认全部"normal"）
- `listed_days`: dict[str, int] | None - 上市交易日数（默认全部满足）

**输出**：
- `candidates`: list[StockCandidate] - 候选股票列表
- `stats`: dict - 统计信息

**统计信息字段**：
```python
{
    "total_universe": 5000,           # 股票池总数
    "filtered_basic": 4500,           # 基础过滤后
    "filtered_liquidity": 3000,       # 流动性过滤后
    "filtered_trading": 3000,         # 交易状态过滤后
    "eligible_for_ranking": 3000,     # 可排序数量
    "in_target_percentile": 600,      # 目标百分位内
    "final_selected": 30,             # 最终选中
    "insufficient_candidates": False  # 候选不足标记
}
```

**执行流程**：
1. 基础资格过滤（ST、上市时长）
2. 流动性过滤（ADV20、停牌）
3. 市值排序（升序）
4. 计算百分位
5. 筛选1%-20%范围
6. 选择前30只

---

**方法 2**: `compute_target_weights(candidates)`

**功能**：计算目标权重（等权）

**输入**：
- `candidates`: list[StockCandidate]

**输出**：
- dict[str, float] - {symbol: weight}

**算法**：
```python
weight_per_stock = target_budget / len(candidates)  # 0.9 / 30 = 0.03
```

---

**方法 3**: `compute_target_shares(candidates, weights, total_equity)`

**功能**：计算目标股数（整手约束）

**输入**：
- `candidates`: list[StockCandidate]
- `weights`: dict[str, float] - 权重字典
- `total_equity`: float - 总资产

**输出**：
- dict[str, int] - {symbol: shares}，100的整数倍

**算法**：
```python
target_value = total_equity * weight  # 1,000,000 * 0.03 = 30,000
raw_shares = target_value / close     # 30,000 / 10 = 3,000
shares = int(raw_shares // 100) * 100 # 2,900（整手）
```

## 6️⃣ 账户模块 (`backend/portfolio.py`)

**功能**：多股票持仓管理、调仓执行、费用计算、T+1限制

### 核心类

#### `FeeConfig` (配置类)
**功能**：费用配置

**参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `commission_rate` | float | 0.0003 | 佣金费率（万三） |
| `min_commission` | float | 5.0 | 最低佣金（元） |
| `stamp_tax_rate` | float | 0.0005 | 印花税率（2023-08-28起） |
| `transfer_fee_rate` | float | 0.00001 | 过户费率 |

**方法**: `calculate(amount, side, date)`

**输入**：
- `amount`: float - 成交金额
- `side`: Literal["buy", "sell"] - 买卖方向
- `date`: str - 交易日期

**输出**：
```python
{
    "commission": 15.0,    # 佣金
    "stamp": 50.0,         # 印花税（仅卖出）
    "transfer": 1.0,       # 过户费
    "total": 66.0          # 总费用
}
```

**算法**：
```python
# 佣金：买卖双向
commission = max(5.0, amount * 0.0003)

# 印花税：仅卖出，税率按日期
if side == "sell":
    stamp = amount * (0.0005 if date >= "2023-08-28" else 0.001)

# 过户费：买卖双向
transfer = amount * 0.00001
```

## 7️⃣ 回测模块 (`backend/backtest.py`)

**功能**：集成选股、账户管理和历史模拟

### 核心类

#### `BacktestEngine` 类

**初始化参数**：
- `selection_config`: SelectionConfig | None
- `fee_config`: FeeConfig | None
- `initial_cash`: float - 默认1,000,000
- `slippage_bps`: float - 默认5.0

**属性**：

- `portfolio`: Portfolio - 账户
- `selection_config`: SelectionConfig - 选股配置

---

**方法**: `run()`

**功能**：执行完整回测

**输入**：

## 1️⃣0️⃣ 因子分析模块 (`backend/factor_analysis.py`)

**功能**：评估小市值策略的真实表现和超额收益来源，通过Rank IC、分组收益、因子暴露、行业中性Alpha四个维度提供深度分析

### 核心类

#### `FactorAnalyzer` 类
**功能**：因子分析器

**初始化参数**：
- `backtest_result`: dict - 回测结果

**方法 1**: `calculate_rank_ic()`

**功能**：计算市值因子的秩相关系数序列

**输出**：
```python
{
    "rank_ic_series": [
        {
            "signal_date": "2024-01-31",
            "ic": 0.15,
            "p_value": 0.08,
            "sample_size": 30
        },
        ...
    ],
    "mean_ic": 0.10,
    "ic_std": 0.12,
    "ic_t_stat": 0.83
}
```

**算法**：
1. 遍历每个月末信号日期
2. 获取该日期的候选股票市值排名
3. 计算后续持股期间的日收益
4. 对市值排名 vs 收益做Spearman秩相关
5. 输出IC值、p-value和样本数

**关键特征**：
- 时间对齐：防止数据穿越
- 秩相关：对异常值更稳健
- 日级别收益：捕捉高频选股能力

---

**方法 2**: `calculate_group_returns()`

**功能**：计算五分组收益分析

**输出**：
```python
{
    "groups": {
        "1": {
            "group_id": 1,
            "avg_return": 0.052,
            "cumulative_return": 0.65,
            "symbols_count": 6,
            "avg_market_cap": 1000000000
        },
        ...
    },
    "monotonicity_check": True,
    "group1_excess_return": 0.044
}
```

**分组方法**：
- 按市值升序排列候选股票
- 平均分成5组（或按实际数量）
- 计算每组的日均收益和累计收益

**关键指标**：
- 单调性：组1收益 ≥ 组2 ≥ ... ≥ 组5
- 超额收益：组1收益 - 组5收益

---

**方法 3**: `calculate_exposure()`

**功能**：计算策略的因子暴露

**输出**：
```python
{
    "strategy_industry_weights": {"C34": 0.95, "J66": 0.05, ...},
    "benchmark_industry_weights": {"C34": 0.45, "J66": 0.55, ...},
    "industry_overweight": {"C34": 0.50, "J66": -0.50, ...},
    "avg_market_cap": 850000000,
    "benchmark_avg_market_cap": 5000000000,
    "avg_adv": 25000000,
    "benchmark_avg_adv": 80000000
}
```

**暴露维度**：
- **行业权重**：策略vs基准的行业配置差异
- **市值暴露**：策略平均市值 vs 基准平均市值
- **流动性暴露**：策略平均ADV20 vs 基准平均ADV20

**基准定义**：
- 全市场等权重（每只股票权重 = 1/总数量）

---

**方法 4**: `calculate_alpha_decomposition()`

**功能**：分解超额收益来源

**输出**：
```python
{
    "total_excess_return": 0.05,
    "industry_attribution": 0.02,
    "security_selection_alpha": 0.03,
    "alpha_ratio": 0.60
}
```

**分解公式**：
```
总超额收益 = 行业配置贡献 + 选股Alpha

行业配置贡献 = Σ(行业权重差异 × 行业超额收益)
选股Alpha = 总超额收益 - 行业配置贡献
Alpha比率 = 选股Alpha / 总超额收益
```

**解读**：
- Alpha > 0：真实的选股能力
- Alpha < 0：选股拖累整体表现
- Alpha比率越高：选股贡献越重要

---

**方法 5**: `run_analysis(include_html_report=True)`

**功能**：执行完整因子分析

**输出**：
```python
{
    "rank_ic": {...},
    "group_returns": {...},
    "exposure": {...},
    "alpha": {...}
}
```

### 新增功能概览

阶段三完成了小市值策略研究工作台的**因子分析模块**，通过4个核心维度评估策略的真实表现和超额收益来源：

| 分析维度 | 模块 | 说明 |
|---------|------|------|
| **Rank IC时间序列** | `factor_analysis.py` | 市值因子与收益的秩相关系数 |
| **五分组收益分析** | `factor_analysis.py` | 按市值分组后的收益对比与单调性 |
| **因子暴露分析** | `factor_analysis.py` | 策略vs基准的行业、市值、流动性差异 |
| **行业中性Alpha** | `factor_analysis.py` | 控制行业后的真实选股能力 |

---

### 核心指标解读

#### 1. Rank IC 时间序列

**定义**：
- IC = 市值排序 vs 后续持股期间收益的Spearman秩相关系数
- IC ∈ [-1, 1]，值越接近1表示小市值越容易涨，越接近-1表示越容易跌

**关键统计量**：
- **平均IC**：所有月份IC的平均值，>0.1表示因子有正向预测能力
- **IC T-Stat**：平均IC / IC标准差，>2表示统计显著
- **P-Value**：每月IC的统计显著性检验，<0.05为显著

**解读示例**：
```
平均IC: 0.10
IC标准差: 0.12
T-Stat: 0.83 (= 0.10 / 0.12)
→ 说明：因子有选股能力但不稳定，统计显著性不强
```

---

#### 2. 五分组收益分析

**分组方法**：
- 每月末选股时，将候选30只股票按市值升序分成5组（每组6只）
- 跟踪每组在持股期间的平均收益和累计收益

**关键指标**：
- **单调性**：第1组收益 ≥ 第2组 ≥ ... ≥ 第5组？若是，表示小市值溢价存在
- **超额收益**：第1组收益 - 第5组收益，越大表示策略的小市值暴露越有效
- **收益分布**：各组的平均日收益率和年化收益率

**解读示例**：
```
第1组（最小市值）: 年化收益 65%
第5组（最大市值）: 年化收益 10%
超额收益: 55%，单调性✓

→ 说明：强烈的小市值溢价，策略逻辑有效
```

---

#### 3. 因子暴露分析

**三大维度**：

**A. 行业权重超配**
```
策略行业权重 vs 基准行业权重
超配权重 = 策略权重 - 基准权重

示例：
制造业：超配+15% → 策略集中在小市值密集的制造业
```

**B. 市值暴露**
```
策略平均市值 vs 基准平均市值
相对比例 = 策略平均市值 / 基准平均市值

示例：
8.5亿 / 50亿 = 17% → 强烈的小市值暴露
```

**C. 流动性暴露**
```
策略平均ADV20 vs 基准平均ADV20
相对比例 = 策略平均ADV20 / 基准平均ADV20

示例：
2500万 / 8000万 = 31% → 流动性风险相对较高
```

---

#### 4. 行业中性Alpha分解

**公式**：
```
总超额收益 = 行业配置贡献 + 选股Alpha

其中：
- 行业配置贡献 = Σ(行业权重差异 × 该行业超额收益)
- 选股Alpha = 总超额收益 - 行业配置贡献
- Alpha比率 = 选股Alpha / 总超额收益 (%)
```

**解读示例**：
```
总超额收益: 5%
行业配置贡献: 2%  (得益于超配表现好的制造业)
选股Alpha: 3%     (真正的选股能力)
Alpha比率: 60%    (60%的超额收益来自选股，40%来自行业配置)

→ 说明：策略有较强的选股能力（Alpha>0），
行业配置也有一定帮助
```

### 使用工作流

**完整流程**：

```bash
# 步骤1：运行回测
curl -X POST http://127.0.0.1:8001/api/backtest \
  -H "Content-Type: application/json" \
  -d '{
    "start_date": "2023-01-01",
    "end_date": "2024-12-31",
    "stock_filter": "mainboard"
  }'

# 记录返回的 experiment_id，例如：

# 步骤2：运行因子分析
curl -X POST http://127.0.0.1:8001/api/factor-analysis \
  -H "Content-Type: application/json" \
  -d '{
    "experiment_id": "5e3b2a1c-9f4d-41e2-8b7c-3d5e9f2a1b4c",
    "include_html_report": true
  }'

# 步骤3：查看生成的报告
# - JSON报告: outputs/{experiment_id}/factor_analysis.json
# - HTML报告: outputs/{experiment_id}/factor_report.html (浏览器打开)
```

### 应用场景

| 场景 | 分析维度 | 关键问题 |
|------|---------|---------|
| **验证小市值因子有效性** | Rank IC + 五分组 | 是否存在稳定的小市值溢价？ |
| **理解策略超额收益来源** | Alpha分解 | 选股能力vs行业配置的贡献？ |
| **风险评估** | 因子暴露 | 流动性/市值风险有多大？ |
| **行业中立性检验** | 暴露 + Alpha | 是否过度集中于特定行业？ |
| **策略改进方向** | 全维度 | 后续应加强哪些方面？ |

### 与其他模块的关系

```
选股逻辑 (selection.py)
    ↓
调仓执行 (portfolio.py)
    ↓
回测模拟 (backtest.py)
    ↓
因子分析 (factor_analysis.py) ← 核心分析
    ↓
报告生成 (reports.py)
    ↓
API端点 (app.py) ← /api/factor-analysis
```

**关键指标映射**：
- Selection逻辑 → Group Returns单调性
- Portfolio执行成本 → Alpha分解中的持仓差异
- Backtest净值 → Rank IC的预测能力验证
- 因子暴露 → 风险特征描述
